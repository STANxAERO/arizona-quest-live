# ARIZONA Quest Live

[English documentation](README.md) · [Скачать приложения](https://github.com/STANxAERO/arizona-quest-live/releases)

Беспроводной просмотр изображения одного глаза с двух Meta Quest в локальной сети. Создано для занятий VR-граффити в Центре хип-хоп культуры АРИZОНА. Без облачного посредника, подписки и WebStream VR. Это независимый лаунчер для [scrcpy](https://github.com/Genymobile/scrcpy) и Android Debug Bridge (ADB), а не продукт Meta или форк WebStream VR.

## Установка

**Windows 11 x64:** скачайте Windows ZIP из Releases, распакуйте целиком в доступную для записи папку и откройте `ARIZONA Quest Live.exe`. При первом запуске подтвердите загрузку официального scrcpy 5.0.1; SHA-256 архива проверяется. Используются Windows PowerShell 5.1 и .NET Framework 4.x. Обычно права администратора не нужны. Если Windows блокирует загруженные сценарии, проверьте контрольную сумму и исходный код, затем разблокируйте только доверенный ZIP через «Свойства» перед повторной распаковкой либо только соответствующие сценарии. Не отключайте SmartScreen и не меняйте системную политику выполнения PowerShell.

**macOS 14+ на Apple Silicon:** скачайте macOS ZIP, распакуйте и перенесите приложение в «Программы». Установите [Homebrew](https://brew.sh/), если его нет, затем выполните в Терминале:
```sh
brew install scrcpy python@3.13
brew install --cask android-platform-tools
```
Либо запустите прилагаемый Install dependencies.command. Откройте ARIZONA Quest Live.app. Сборка имеет локальную ad-hoc подпись, но не подписана Developer ID и не нотарифицирована Apple. Проверьте контрольную сумму и исходники; если macOS заблокировала запуск, разрешите именно этому приложению открыться через «Системные настройки → Конфиденциальность и безопасность». Разрешите доступ к локальной сети при запросе. Intel Mac в этот релиз не входит.

## Первоначальная настройка каждого шлема на каждом компьютере

1. Включите режим разработчика Quest по официальной инструкции Meta, разрешите USB-отладку.
2. Подключите компьютер и шлем к одной доверенной локальной сети. Подключите **один** шлем USB-кабелем с передачей данных, наденьте шлем и подтвердите отладку для этого компьютера. У нового Mac/ПК отдельная авторизация ADB.
3. Откройте лаунчер. Для Headset 1 нажмите **USB / Wi-Fi** (Windows: **Set up USB / Wi-Fi**). Подтвердите включение сетевого ADB. Лаунчер сохранит серийный номер шлема и его текущий IP.
4. После успешного подключения по Wi-Fi отключите кабель. Повторите для Headset 2.
5. Запустите VR-приложение, например Graffism. Нажмите **Start both** или заново откройте лаунчер — для каждого зарегистрированного и доступного шлема откроется своё окно.

## Ежедневное использование

Включите оба шлема, подключите их к одной локальной сети, запустите VR-приложение и откройте Quest Live. Лаунчер проверяет известные ADB-подключения и сохранённые адреса, при необходимости ищет порт 5555 в непосредственно подключённой частной IPv4-сети (не шире /24), проверяет серийный номер и восстанавливает завершившиеся процессы просмотра. Интернет для самой видеотрансляции не требуется. Настройки роутера не изменяются.

**Stop** — остановка конкретного шлема; закрытие окна просмотра может вызвать его автоматическое открытие. Закрытие лаунчера завершает обе трансляции. На обеих платформах есть выбор глаза, целевая частота до 30 FPS и переподключение. На Mac дополнительно доступны обрезка 16:9, качество до 60 FPS, перезапуск и кнопка Graffism. Для применения новых параметров перезапустите поток. Фактические FPS и задержка зависят от сети, шлема и сцены.

## Возможные проблемы и безопасность

- После полной перезагрузки Quest сетевой ADB может отключиться. Повторите USB-настройку. Лаунчер не может удалённо выдать разрешение отладки новому компьютеру или включить отключённый порт.
- Не находится шлем: проверьте режим разработчика, USB-авторизацию, одну доверенную сеть, отсутствие изоляции клиентов и доступность TCP 5555. Поиск не предназначен для маршрутизируемых подсетей, гостевых сетей и VPN.
- Чёрный экран: запустите VR-приложение и перезапустите поток. На некоторых сборках Horizon OS системное меню не захватывается. Лаунчер не обходит защиту контента или ОС. Если другой инструмент менял Android-разрешение, верните штатное значение самостоятельно: лаунчер обнаруживает переопределение, но не меняет настройки экрана.
- Используйте только свои или явно разрешённые устройства, с информированным согласием участников (при необходимости законных представителей). Не открывайте порт ADB 5555 в интернет. Для занятий используйте доверенную изолированную сеть. После занятий остановите просмотр; если сетевой ADB больше не нужен, переключите его обратно на USB (при подключённом ADB: `adb -s <адрес-шлема> usb`).
- Публичная версия начинается с пустых настроек. Для замены зарегистрированного шлема закройте приложение, сохраните резервную копию и удалите settings.json, затем зарегистрируйте оба заново. Windows: `%LOCALAPPDATA%\ARIZONA Quest Live Public\settings.json`; macOS: `~/Library/Application Support/ARIZONA Quest Live Public/settings.json`. Не публикуйте настройки и ключи ADB.
- Офлайн-установка Windows: скачайте официальный архив scrcpy v5.0.1 win64, проверьте SHA-256 (см. windows/Setup.ps1), распакуйте его содержимое в папку scrcpy рядом с лаунчером.
- Это предварительный релиз. Исходная локальная версия проверялась на двух Quest 3S с разными сборками Horizon OS, Windows 11 и macOS Apple Silicon. Проверки публичной сборки указаны в описании релиза. Другие модели, версии ОС, полная перезагрузка и фактическая смена IP не сертифицированы.

## Исходники и сборка

Windows: Launcher.cs — нативный загрузчик .NET; QuestLive.ps1 — WinForms-интерфейс; DiscoverQuest.ps1 — поиск. Компиляция через csc .NET Framework с /target:winexe /reference:System.Windows.Forms.dll. Три PS1-файла должны находиться рядом с EXE и иметь кодировку UTF-8 с BOM для Windows PowerShell 5.1.

macOS: `bash macos/build.sh` собирает приложение Apple Silicon с использованием Swift toolchain из Xcode. Python-скрипт поиска входит в пакет, ADB/Python/scrcpy устанавливаются через Homebrew.

Лицензия MIT относится к нашему коду лаунчера. scrcpy — отдельный проект Genymobile под Apache-2.0; Android SDK Platform Tools распространяются по применимым условиям Google. Сторонние компоненты устанавливаются отдельно из официальных источников. В архивы не включены сторонние бинарники, приватные ключи, личные настройки и проприетарный сервис кастинга Meta.
